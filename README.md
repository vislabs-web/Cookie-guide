# Teyvat Lab

A responsive, single-file Genshin Impact character-build analyzer and tracker.

## Features
- Enter character, role, level, weapon, CRIT Rate, CRIT DMG, ATK, HP, Elemental Mastery, and Energy Recharge.
- Generate a general heuristic score, stat-balance bars, and upgrade suggestions.
- Save, load, delete, and export builds as JSON.
- Local browser storage; no account or backend required for this demo.
- Mobile-responsive dark interface.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages build. GitHub will display the published URL in the Pages settings.

## Important scoring note
The score is a general heuristic, not an official Genshin Impact metric or a validated character-specific optimizer. Optimal stats depend on character scaling, weapon, artifacts, team composition, reactions, and rotation. Treat suggestions as starting points, not definitive build advice.

## Project note
This starter currently stores saved builds in the current browser only. It does not provide cloud accounts or cross-device syncing.
